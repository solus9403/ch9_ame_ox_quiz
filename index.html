게임 설정

듣기 → 자동 타이머

예: 3회라면 name → game을 세 번 들려줍니다.
마지막 단어가 끝나면 설정한 시간의 타이머가 자동으로 시작됩니다. 라운드마다 ‘듣기 시작’을 한 번 눌러 주세요.

실제 녹음으로 발음 듣기

직접 녹음했거나 사용 가능한 발음 파일을 불러오세요. 예: name.mp3, game.wav, board_game.mp3. 네이버 사전 음원은 이 파일에 포함되어 있지 않습니다.

등록된 녹음이 없습니다. 파일은 현재 창에서만 유지되며, 다시 열면 재선택해야 합니다.

단어별 녹음 확인 · 네이버 사전 열기

사전은 새 탭에서 열립니다. 해당 페이지의 발음 버튼을 눌러 주세요. 철자와 뜻이 보이므로 수업 준비나 정답 확인 때 사용하세요.

목소리를 먼저 들어보세요

위 목록에서 목소리를 고르고 미리 들어보세요. 마음에 들면 ‘이 목소리 적용’을 누르세요.

미리듣기: name → game → same → gum
아래 발음 속도가 미리듣기에도 적용됩니다. ‘Natural / Neural / Premium / Enhanced’ 표시가 있는 음성을 먼저 배치합니다. 이름에 따른 우선순위이며, 실제 자연스러움은 들어보고 선택해 주세요.

두 단어 사이에 0.8초의 간격을 둡니다. 실제 속도는 기기의 음성에 따라 달라집니다.

혼합 모드는 난이도별 문제 수의 차이가 1개 이내가 되도록 골고루 섞습니다. 같은 문제는 한 게임 안에서 반복하지 않습니다.

선생님 진행 안내 · 먼저 읽어 주세요
  1. 학생은 자기 번호를 확인하고 자리에서 일어납니다.
  2. 단어를 듣고, 생각 시간 종료 신호에 동시에 O 또는 X 동작을 합니다.
  3. 정답을 공개하고 모두 함께 두 단어를 따라 말합니다.
  4. 선생님이 아래 번호판에서 틀린 학생을 선택한 뒤 ‘생존 확정’을 누릅니다. 선택은 확정 전 다시 눌러 취소할 수 있습니다.
  5. 한 명만 남으면 즉시 우승! 마지막 라운드에 여러 명이 남으면 공동 우승입니다.
  6. 전원 탈락하면 직전 생존자를 복귀시키고 다음 문제로 진행합니다. 마지막 문제라면 공동 우승입니다.

기준은 모음부터 마지막 자음까지 같은가입니다. name–game은 O, game–gain은 X입니다. 상 단계의 game–games도 마지막 /z/ 때문에 X입니다.

하: 익숙한 단어와 뚜렷한 소리 차이 · 중: 같은 첫소리에서 모음 비교 · 상: 겹자음, 마지막 자음, 긴 단어.
탈락한 학생도 앉아서 듣기와 따라 말하기에 계속 참여합니다.

한 화면을 교사가 조작하는 게임입니다. 학생별 기기 접속이나 자동 응답 수집은 없습니다. 음성은 브라우저·기기의 영어 음성을 사용하며, 환경에 따라 인터넷 연결이 필요할 수 있습니다. 수업 전 확인하거나 교사가 직접 읽어 주세요.
